## About me

I'm Amit, a full stack software engineer based in India. I build web applications, Flutter apps, backend APIs and interactive websites, with attention to the work behind the interface: authentication, data access, payments, background jobs and deployment.

My current focus is **[Vacancyi](https://vacancyi.com)**, a platform for jobs, admissions, scholarships and assisted applications, with a Next.js website, NestJS API and Flutter user app. My work also includes **[College Club](https://collegeclub.io)** and websites for businesses, studios and community platforms.

- **Web:** React, Next.js, TypeScript and reusable interface components.
- **Mobile:** Flutter apps with secure sessions, API integration and Android release builds.
- **Backend:** NestJS and Express APIs, authorization, validation and database design.
- **Data and jobs:** PostgreSQL, Prisma, Redis, cursor pagination and BullMQ.
- **Interaction:** GSAP and Framer Motion for purposeful animation.
- **Delivery:** Docker, GitHub Actions, automated checks and deployment workflows.

## How I work

- **Start with the workflow.** Define the user journey, API contract and failure cases before expanding the implementation.
- **Keep access explicit.** Validate inputs, authorize private resources and avoid exposing sensitive data in responses or logs.
- **Bound the work.** Use indexed queries, server-side filtering, cursor pagination and controlled retries.
- **Make retries safe.** Use idempotency for payments and background jobs where duplicate execution is possible.
- **Build reusable interfaces.** Keep components and widgets focused, accessible and consistent across screens.
- **Test meaningful behavior.** Cover success paths, authorization boundaries and relevant failure cases.
- **Measure performance.** Check rendering, request volume and bundle size instead of assuming an implementation is fast.
- **Use motion deliberately.** Animation should explain state, guide attention or support navigation.
